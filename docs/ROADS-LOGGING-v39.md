# v39 — controlled forestry and road materials

Select a forest plot, then “Позначити для лісорубів”. Gold outlines show designated
plots. Select again to cancel. Unmarked forests are protected, including legacy
saves. A cut requires 60 seconds of work plus travel and processing. Cancellation
interrupts pending cuts. Plot validity is checked again before removing a tree.

Select an existing road to upgrade it: dirt → cobble (12 stone) → dressed stone
(24 stone). Materials persist independently of technology; motor research no longer
turns every road into pavement. Right-angle two-link bends use sampled quadratic
curves with matching endpoints. Junction geometry is unchanged.

Vehicle width reduced from .95 to .46 world units. Vehicles do not bounce; walking
frames follow distance rather than elapsed wall time. Facing persists at stops.
Vehicle/walker speeds are reduced. Existing four-frame sprites remain: this is not
a new directional character/vehicle animation atlas. Diagonal vehicle turning,
traffic avoidance and complete reference-quality materials still need work.

No changes to chemistry visuals. No signed store build in this iteration.
